

## System Package Requirements for running kidpy3

You will need to install the following packages to use kidpy3:

### Ubuntu 24.04.3 LTS
```
sudo apt-get install libhdf5-dev libhdf5-103-1t64 libhdf5-hl-100t64
```

## System package requirements for building kidpy3
